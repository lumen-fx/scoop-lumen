# scoop-lumen

The Scoop bucket for Lumen, the UI framework.

```
scoop bucket add lumen https://github.com/lumen-fx/scoop-lumen
scoop install lumen
```

That installs `lumenc` and the Lumen runtime library from the latest release of
[lumen-fx/lumen](https://github.com/lumen-fx/lumen). The MSI installer is the
other Windows option; see the Lumen install docs.

`bucket/lumen.json` is written by the release workflow in the Lumen repository
and points at the release archives; edit it there, not here.
